# 小芽學習島

![App icon](delivery/app-icon.png)

給 2～8 歲孩子玩的 Android 海島學習遊戲，支援繁體中文與英文。孩子可以搭船到不同地點，修橋、裝水果、送貨、畫畫、調時鐘及幫角色準備出門。

## 下載與開始

安裝 [小芽學習島 1.0.1 APK](delivery/little-sprout-island-1.0.1.apk)，需要 Android 8.0 或以上。此檔使用專案專屬發布簽章。

1. 將 APK 傳到 Android 手機或平板，依系統指引安裝；部分手機會先要求掃描與確認來源。
2. 開啟後點「開始玩」，由家長選語言、起始難度、休息時間並設定四位數 PIN。
3. 點地圖上的目的地，搭船開始遊玩。聲音按鈕可以切換靜音。

PIN 由家長自己設定，沒有預設密碼或線上找回功能。清除 App 資料會失去設定與本機進度。

## 七個地方可以玩什麼？

| 地點 | 玩法 |
| --- | --- |
| 海灘 | 找同色的傘、配對形狀，練習大小、高矮、桌上桌下、分類、規律、相同不同與多少。 |
| 小橋 | 試放不同長度的木板，選合適的木板讓兔子過河。 |
| 水果攤 | 第 1 階自由混裝水果後交給兔子；其餘階段按訂單增減水果，進階提供混合訂單與 20 以內簡單加減。 |
| 碼頭 | A～Z 每組四件物品，共 104 張圖卡；可自由選物送貨，也能練圖片配對及聽英文選物。 |
| 沙灘畫畫 | 自由畫或跟著筆畫描數字、大小寫字母及 37 個注音；海浪可以洗平沙面，作品可存入作品簿。 |
| 車站 | 轉動時針／分針或使用按鈕調時間，準備好後讓火車出發；包含整點、半點及五分鐘刻度。 |
| 小屋 | 第 1 階自由觀察與穿搭，第 2 階挑合適用品，第 3 階辨認英文天氣句，第 4 階聽音選天氣；靜音時用圖片提示。 |

完成任務會看到角色移動、物品送達或火車出發，可以再玩一次。地圖上的記號保存遊玩紀錄，所有地方都能自由進入。

## 難度與聲音

家長可選幼幼班、小班、中班、大班或 6～8 歲作為起點；場景中的 1～4 可以再調整任務難度。班級只是推薦起點，不是學習能力評量。

一般提示可選中文或英文。英文單字維持英文發音，注音使用教育部的符號錄音。靜音時會提供圖片訂單或視覺提示，不把看圖完成記成聽力完成。

X 組用來找「單字裡的 X」，包括 x-ray、box、fox、six，後三者不是 X 開頭。unicorn 是想像動物。

## 家長設定與休息

家長區可管理語言、聲音、難度、本週主題與資料清除。選水果、動物或天氣主題時，相關地點會優先出現在地圖上。

預設每 15 分鐘提醒休息，也可改成 10／20 分鐘或關閉。時間到會在當題／當筆之後進入休息，最遲 30 秒；休息兩分鐘後可繼續，家長也能輸入 PIN 提前結束。這個功能不會鎖住整台裝置。

## 隱私與教材

App 內沒有廣告、帳號、社群、購物或追蹤分析，已提供的圖片與錄音離線可用。設定、島嶼進度、草稿和作品保存在裝置上，不連線上傳。Android 雲端備份與裝置移轉已排除 App 資料。

清除學習進度會刪除島嶼狀態、草稿和作品，保留設定及 PIN；重設全部資料也會刪除設定與 PIN。解除安裝會失去本機資料。

注音字形、筆順與發音來自 [教育部《國語注音符號手冊》開放部件](https://language.moe.gov.tw/001/Upload/files/site_content/M0001/juyin/)，採 CC BY 4.0。其他物件圖稿為本專案自製向量插畫。英文錄音使用 Piper／公有領域 LJ Speech 模型，中文操作指令使用 MIT 授權 MeloTTS，在開發時產生並打包；App 遊玩時不連接語音服務。

教材供日常遊戲與練習，沒有學力診斷或官方幼兒園課程認證。各校教學進度不同，家長可選相關主題搭配使用。
